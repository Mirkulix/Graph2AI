the problem

When agents share what they know by copying text, the knowledge rots.

01 / DUPLICATED

Session B redoes session A's work

A's findings live in a transcript B never sees. So B rediscovers them — and burns the tokens twice.

02 / STALE

Confident, and wrong

An agent asserts “auth uses bcrypt” because it read it three steps ago. Nobody checked. It's argon2 now.

03 / GONE

Close the tab, lose the context

There's no durable, shared memory. Every new session starts cold, re-learning the same codebase.

the product

Agents exchange signed, evidence-backed facts — not conversation.

Every fact carries who observed it, when, and the exact file and line that proves it. A later agent checks the claim instead of trusting it. Three things make that real, not a wiki with extra steps:

?→✓

A proposal is never a fact

An agent can suggest something, but it stays invisible to the next agent's context until real evidence promotes it. Enforced by the type system, not by trust.

🔑

Signed, so provenance is proof

Every change is Ed25519-signed by a key you trust. “Who said this” is cryptographic — not a string anyone can claim. Rotation and revocation built in.

⑃

Conflicts surface, never overwrite

Two agents disagree? Both keep their evidence, and the conflict shows up for a human to settle. Nothing is silently lost.
