# QLMS Python Reference Parser

Stdlib-only Python parser + HMAC-SHA256 verifier for the QLMS v1.1 wire
format. Lives in the repo to prove language-independence for the
Linux Foundation AAIF submission (spec §16.4 item 6).

## Files

| File | Role |
|------|------|
| `parser.py` | Pure-Python parser (v1 + v2) and verifier. No third-party deps. |
| `golden_test.py` | Golden-file smoke test — reads fixtures generated by Rust and asserts Python agrees. |
| `fixtures/*.qlms` + `*.json` | Binary envelopes + metadata emitted by the Rust side. |

## Prerequisites

- Python 3.10 or newer (only `hashlib`, `hmac`, `struct`, `json`, `dataclasses` from stdlib).
- A working Rust/`cargo` toolchain to regenerate fixtures.

## Running the golden test

```bash
# 1. (Re)generate fixtures from the Rust reference implementation.
cargo run -p qlang-agent --example emit_golden

# 2. Run the Python side.
cd bindings/python/qlms_parser
python golden_test.py
```

Expected output (exit code 0):

```
Running 3 QLMS golden fixture(s) from .../fixtures
  PASS v1_unsigned_single  (v1_unsigned, 297 B)
  PASS v2_signed_single  (v2_signed, 428 B)
  PASS v2_signed_two_messages  (v2_signed, 759 B)

3/3 fixtures passed.
```

Run a specific fixture:

```bash
python golden_test.py v2_signed_single
```

## What the test proves

Per QLMS v1.1 §16.4, a conforming implementation must parse and verify
envelopes emitted by another conforming implementation. The fixtures
are deterministic (seeded keypairs), so the Python parser's results are
bit-stable and can be diffed against future spec revisions.

Each v2 fixture exercises:

1. Envelope parse (magic, version, flags, signature block, payload).
2. Public-key derivation from the seed (`SHA-256("qlang-pubkey" || seed)`).
3. SHA-256(payload) agreement with the envelope's payload_hash.
4. Signature verification (`s == SHA-256(SHA-256(r || pubkey || payload_hash))`).
5. Tamper detection — mutating the payload must flip verification to False.

## Library usage

```python
from parser import parse_auto, verify_signed_frame, QlmsSignatureError

data = open("fixtures/v2_signed_single.qlms", "rb").read()
frame = parse_auto(data)

if frame.is_signed and not verify_signed_frame(frame):
    raise QlmsSignatureError("rejecting tampered frame")

for msg in frame.messages():
    print(msg["from"]["name"], "->", msg["to"]["name"], ":", msg["intent"])
```
